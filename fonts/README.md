## Quick Setup & GitHub Push Instructions

To publish these fonts to your new GitHub repository, run the following commands in terminal:

```bash
cd /Users/codefrydev/Desktop/SourceCode/PDFCreator-Fonts
git init
git add .
git commit -m "feat: add complete FryPDF font library (67 fonts)"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

> **Note**: Once pushed, the raw font download URL format will be:
> `https://raw.githubusercontent.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>/main/<FileName.ttf>`
