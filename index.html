Automated Quality Engineering

Automation & Packaging CLI

High-integrity Python tooling for release packaging, catalog synchronization, and cryptographic validation.

📦 package_plugin.py

Builds Release configuration, generates .fryplugin zip archives, calculates SHA256 checksums, and stages to plugins/<id>/.

python3 tools/package_plugin.py --all

🚀 package_runner.py

Compiles standalone runners into native OS applications: macOS .app bundles with branded .dmg and Windows Inno Setup installers.

python3 tools/package_runner.py csharpeditor

🛡️ validate_plugins.py

Validates catalog syntax, verifies zip package contents, checks reverse-DNS IDs, and runs dotnet build on all solutions.

python3 tools/validate_plugins.py

🔤 verify_fonts.py

Inspects all 67 TrueType & OpenType font binaries, checking magic numbers, table headers, and total library sizing.

python3 tools/verify_fonts.py
